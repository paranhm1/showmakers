# ShowMakers Project Rules

## Source of Truth

For this project, follow this order of precedence:

1. ShowMakers business requirements
2. ShowMakers Brand Guidelines
3. ShowMakers Company Profile and real company content
4. WordPress maintainability and client editing requirements
5. Project-specific creative direction
6. Installed design skills such as `design-taste-frontend`
7. Generic frontend conventions

Installed skills are advisory.
They must never override the requirements above.

---

## Platform

This is a WordPress website.

Do NOT change the project to:
- React
- Next.js
- TanStack Start
- Cloudflare-based application architecture
- another JavaScript application framework

unless explicitly requested.

The website should remain practical for ShowMakers staff to update after handover.

Use custom frontend code only when it materially improves the experience
without making routine content maintenance dependent on a developer.

---

## Brand Overrides

The ShowMakers brand system has priority over generic design rules.

The following are explicitly allowed:

- pure or near-pure white
- black / charcoal
- vivid ShowMakers yellow
- intentional contrast between light and dark sections
- large editorial typography
- numbered compositions
- image labels
- unconventional portfolio layouts

Do not reject these treatments merely because an installed skill discourages them.

---

## Visual Direction

The site should feel like a real creative and production agency.

Avoid generic AI-generated website patterns such as:

- repetitive centered hero layouts
- excessive rounded cards
- endless feature grids
- excessive gradients
- SaaS-style dashboard aesthetics
- arbitrary floating UI elements
- decorative animation with no storytelling purpose

Prefer:

- strong art direction
- editorial composition
- photography and video-led layouts
- asymmetry where appropriate
- controlled whitespace
- strong typography
- intentional pacing between sections

---

## Motion

Motion should support storytelling, not demonstrate technical ability.

Do not use maximum animation intensity simply because a design skill recommends it.

Prefer:

- subtle entrance motion
- image reveals
- restrained parallax
- typography transitions
- portfolio interaction
- deliberate page transitions where justified

Avoid:

- constant movement
- excessive scroll hijacking
- animations that delay navigation
- effects that make WordPress maintenance fragile

Performance and usability have priority.

---

## Color Modes

Do NOT build separate light and dark modes unless explicitly requested.

Instead, individual sections may intentionally use:

- white
- black / charcoal
- ShowMakers yellow
- combinations defined by the ShowMakers brand system

Section-level contrast is part of the visual language.

---

## Content Authenticity

Never fabricate:

- clients
- campaigns
- testimonials
- performance metrics
- awards
- team members
- project results

Do not use generated work as if it were real ShowMakers work.

Placeholders must be clearly identifiable as placeholders.

Real ShowMakers portfolio assets and company material always take priority.

---

## Copy

Homepage copy should remain concise and visually strong.

However, do not apply arbitrary copy-length limits to:

- case studies
- project descriptions
- service details
- company information
- contact information

Content length should match the communication need.

---

## Use of Installed Skills

Use `design-taste-frontend` for:

- visual hierarchy
- typography
- spacing
- composition
- interaction ideas
- anti-generic design checks
- frontend polish

Ignore or adapt any skill instruction that conflicts with:

- ShowMakers branding
- WordPress
- maintainability
- accessibility
- performance
- genuine company content
- this AGENTS.md file
